================================================================================
KEY DIFFERENCES: LSTM vs RNN-GRU
================================================================================

Both use URL sequences (256 characters max):

LSTM:
- Complex: 3 gates (input, output, forget) + cell state
- More parameters → Slower training, higher memory
- Better for very long sequences
- Better performance (usually)

RNN-GRU (NEW):
- Simpler: 2 gates (reset, update)
- Fewer parameters → Faster training, lower memory
- Good for moderate-length sequences (256 chars is perfect)
- Fast inference for production

Use case: RNN-GRU is ideal when you want fast training/inference without
much accuracy loss compared to LSTM.
